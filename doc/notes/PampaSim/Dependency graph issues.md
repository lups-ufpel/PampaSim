We need to have a way to edit processes that have already been created. I'd like if we didn't have to write a whole new window for it, I'd much rather we find a way to reuse the process creation window, just populated with the existing selections. Therefore, we tried implementing it with callbacks: each ProcessViewModel stores a list of relevant callbacks for the deletion or editing of itself.

Problem: the ProcessViewModel is separate from the actual process data the simulation actually holds at any given moment. It mirrors the changes the simulation process goes through, but it can only keep that up by reacting to the relevant simulation events as they come. Because of that, if we want to change the actual process data, we need to edit the Process.Arrival event that that ProcessViewModel came from, which is a little more involved.
